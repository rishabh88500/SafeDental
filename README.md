# SafeDental

A dental decision-support prototype for acute dental pain and odontogenic infection. This system is designed to test if adding a safety-aware clinical determinability and abstention layer can reduce unsafe recommendations compared to a baseline LLM.

## Project Structure
- `docs/`: Project memory, research protocol, and architecture documentation.
- `progress/`: Progress tracking and current tasks.
- `data/`: Datasets and index files.
- `corpus/`: Dental knowledge base documents.
- `src/`: Source code.
- `config/`: Configurations.
- `tests/`: Test files.
- `app/`: Frontend applications (e.g., Streamlit).
- `api/`: Backend API.
